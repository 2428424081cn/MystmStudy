# MystmStudy - STM32F103 冷脸萌 (Fumo ᗜ - ᗜ) 活体桌宠

基于 **STM32F103C8T6** 核心板与 **0.96 寸 SSD1306 OLED** 的纯寄存器级裸机项目。
实现了一个 80+ FPS 极限刷新的经典“冷脸萌（Fumo ᗜ - ᗜ）”动态表情活体桌面小宠物。

---

## 🌟 项目特性

- **纯寄存器裸机编程**：零 HAL 库、零标准外设库依赖，极致轻量，透明可控。
- **80+ FPS 极速刷新**：内部 HSI 倍频至 64MHz，高度优化的软件模拟 I2C 与全屏显存双缓冲机制。
- **10 种生动经典表情**：
  - NORMAL（平常冷脸呆萌 `ᗜ - ᗜ`）
  - SHY（害羞脸红 `,,ᗜ - ᗜ,,`）
  - HAPPY（微弯嘴角开朗 `ᗜ ᴗ ᗜ`）
  - POUT（倒 V 委屈嘟嘴 `ᗜ ‸ ᗜ`，带汗滴）
  - ANGRY（怒眉瞪眼 `ᗜ - ᗜ`，带 💢 爆筋）
  - FLIP（暴怒掀桌 `( ╯－︿－)╯╧╧`，带 3D 翻滚飞起的桌子与暴走指示灯联动）
  - SLEEP（舒缓入睡，带浮动升空的 `z Z` 气泡）
  - PEACE（歪嘴笑比耶 `ᗜ ֊ ᗜ ✌`，带剪刀手）
  - KAWAII（猫咪波浪嘴 `:3` `ᗜ 𖥦 ᗜ`）
  - SMUG（被夸暗爽两段式动画 `（ᗜ _ ᗜ）➔（ᗜ ֊ ᗜ）`）
- **生动细腻的眼部物理模拟**：
  - 经典 22×18 像素标志性纯空心 ᗜ 边框（内部完全镂空留白）；
  - 独立张望系统：四处微动注视插值平滑移动；
  - 自然眨眼闭合回弹；
- **自适应按键检测**：按键扫描算法自动学习初始电平，无论按键接地（低有效）或接电源（高有效）均可自动适配。
- **AUTO / MANU 双模式**：支持自主漫游状态机生活模式与手动按键切换，并支持戳一戳（Poke）互动。

## 📌 硬件引脚连接

| 外设模块 | 引脚 | 说明 |
| :--- | :--- | :--- |
| **OLED SCL** | **PB6** | 软件 I2C 时钟线 |
| **OLED SDA** | **PB7** | 软件 I2C 数据线 |
| **板载 LED** | **PC13** | 状态指示灯（低电平点亮，与表情心跳/暴走联动） |
| **按键 K1** | **PA0** | 下一个表情 |
| **按键 K2** | **PA1** | 上一个表情 |
| **按键 K3** | **PA2** | 戳一戳互动（Poke！触发眨眼与表情演进） |
| **按键 K4** | **PA3** | 切换 AUTO（自动漫游）/ MANU（手动控制） |

## 🛠️ 构建与编译

本项目支持 **STM32CubeIDE** 与 **CMake + Ninja** 两种编译方式。

### 方式一：CMake + Ninja 命令行构建
```bash
# 生成并编译 Debug 版本
ninja -C Debug
```

### 方式二：STM32CubeIDE
直接导入本工程文件夹，选择 `Helloworld` 项目，点击编译与调试即可。

### 固件烧录
支持 ST-LINK / J-Link 或 STM32CubeProgrammer 命令行直接烧录：
```bash
STM32_Programmer_CLI.exe -c port=SWD -d Debug/Helloworld.elf -v -rst
```
