# MystmStudy - STM32F103 双目赛博机器人巨眼 (Dual-Screen Cyber Robot Eyes)

基于 **STM32F103C8T6** 与 **两块 0.96 寸 SSD1306 OLED** 的高性能纯寄存器级裸机项目。
将两块屏幕分别作为机器人的**左眼**与**右眼**，实现媲美 Cozmo / Vector / 瓦力机器人的 **68×46 巨型灵动赛博发光双目**（80+ FPS 极限刷新）。

---

## 🌟 项目特性

- **双屏独立总线驱动**：
  - 屏幕 1（左眼）：PB6 (SCL), PB7 (SDA)
  - 屏幕 2（右眼）：PB11 (SCL), PB8 (SDA)
  - 具备独立的 1024 字节双显存缓冲区（共 2048 字节），支持双屏极速突发并发刷新。
- **超大高精发光圆角大眼 (68×46)**：
  - 纯几何与布雷森汉姆平滑圆角裁切算法，支持任意角度眼睑裁切与萌系/冷酷眼神塑造。
- **10 种高表现力机器人情绪**：
  1. `1.NEUTRAL`（赛博大眼·灵动注视）：标志性圆角发光眼 + 萌系双镂空高光 + 平滑环视注视；
  2. `2.HAPPY`（喜笑颜开·月牙弯弯）：下眼睑大幅向上弯曲为治愈笑月弧 + 双颊红晕；
  3. `3.ANGRY`（机械狂暴·鹰目斜瞪）：上眼睑内八字向下重压，眼神如刀锋，伴随额头怒筋与 LED 暴走狂闪；
  4. `4.LOVE`（心花怒放·爱心桃目）：双屏 42×38 巨型饱满心跳爱心，伴随两段式“噗通-噗通”心跳缩放动画；
  5. `5.SKEPTIC`（挑眉审视·半信半疑）：左眼高挑圆睁，右眼眯成细长横缝，经典狐疑神态；
  6. `6.CROSS`（斗鸡眩晕·对眼转圈）：左右双眼紧贴中间缝隙互相斗鸡对视，瞳孔同心圆眩晕旋转；
  7. `7.SAD`（委屈落泪·八字下垂）：上眼睑外八字耷拉下垂，左眼伴随像素泪珠滑落；
  8. `8.SHOCK`（震惊圆目·目瞪口呆）：大眼极限撑大到 76×52，中心瞳孔急剧收缩；
  9. `9.SCANNER`（赛博雷达·红外扫描）：高科技十字准星雷达瞄准框 + 贯穿屏幕的高速水平扫描光束；
  10. `10.SLEEP`（待机休眠·沉睡呼吸）：双眼合拢为微弧呼吸发光条，屏幕浮动升起 `z Z` 气泡。
- **灵动眼球注视与眨眼**：
  - 注视平滑插值（阻尼逼近目标视角）；
  - 独立眨眼步进引擎与眼球微动呼吸律动。
- **自适应按键检测**：按键扫描算法自动学习初始电平，无论接地或接电源均可精准触发。

## 📌 硬件引脚连接

| 外设模块 | 引脚 | 说明 |
| :--- | :--- | :--- |
| **屏幕 1 (左眼) SCL** | **PB6** | 软件 I2C1 时钟 |
| **屏幕 1 (左眼) SDA** | **PB7** | 软件 I2C1 数据 |
| **屏幕 2 (右眼) SCL** | **PB11** | 软件 I2C2 时钟 |
| **屏幕 2 (右眼) SDA** | **PB8** | 软件 I2C2 数据 |
| **板载 LED** | **PC13** | 状态指示灯（心跳双闪/暴走频闪/呼吸灯） |
| **按键 K1** | **PA0** | 下一个机器人表情 |
| **按键 K2** | **PA1** | 上一个机器人表情 |
| **按键 K3** | **PA2** | 戳一戳互动（Poke！触发眨眼与表情演进） |
| **按键 K4** | **PA3** | 切换 AUTO（自动生活漫游）/ MANU（手动控制） |
