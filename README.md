# MystmStudy - STM32F103 双屏极速赛车与冷脸萌 (Dual-Screen Racing & Fumo)

基于 **STM32F103C8T6** 核心板与 **两块 0.96 寸 SSD1306 OLED** 的高性能纯寄存器级嵌入式项目。
将两块屏幕与 4 按键完美结合，打造了一款 **80+ FPS 极限流畅度的双屏极速公路赛车游戏**，并与经典 **冷脸萌 (Fumo ᗜ - ᗜ) 活体桌宠** 实现了全功能三合一联动！

---

## 🌟 项目特性

- **双屏独立总线驱动**：
  - 物理左屏（屏幕 2）：SCL=PB11, SDA=PB8
  - 物理右屏（屏幕 1）：SCL=PB6,  SDA=PB7
  - 独立双显存突发传输，实测刷新率达到 **80+ FPS**。
- **双屏极速赛车游戏 (Outrun Racing)**：
  - **右屏 (赛道主视界)**：3 车道公路、飞速流动的黑白路肩道石与车道虚线；玩家操控超跑躲避慢速轿车与加长大卡车；拾取加分金币与闪电氮气罐；撞车爆炸动画与最高分记录；
  - **左屏 (科技仪表盘 + Fumo 副驾)**：实时数字时速（0~240 KM/H）、1~6 挡智能换挡、氮气能量槽；**副驾驶冷脸萌实时情绪联动**（巡航戴酷酷墨镜、氮气喷射兴奋开朗、撞车瞬间暴怒掀桌！）；
- **经典冷脸萌桌宠全功能保留**：
  - 纯正 22×18 空心 ᗜ 大眼；
  - 10 种经典表情（平常、害羞、开心、嘟嘴、生气、掀桌、睡觉、比耶、卖萌、暗爽）；
  - 支持 **【双子萌 TWIN】**（双屏两只对视萌宠）与 **【合体大脸 MERGE】**（双屏拼接一张大脸）！
- **K4 一键三合一循环切换**：
  - 随时在 `[双子萌 TWIN]` ➔ `[合体大脸 MERGE]` ➔ `[极速赛车 RACING]` 之间自由切换！

## 📌 硬件引脚连接

| 外设模块 | 引脚 | 说明 |
| :--- | :--- | :--- |
| **物理左屏 (屏幕 2) SCL** | **PB11** | 软件 I2C2 时钟 |
| **物理左屏 (屏幕 2) SDA** | **PB8** | 软件 I2C2 数据 |
| **物理右屏 (屏幕 1) SCL** | **PB6** | 软件 I2C1 时钟 |
| **物理右屏 (屏幕 1) SDA** | **PB7** | 软件 I2C1 数据 |
| **板载 LED** | **PC13** | 状态指示灯（赛车氮气推进频闪 / 桌宠心跳呼吸） |
| **按键 K1** | **PA0** | 赛车向左变道 / 桌宠上一表情 / 撞车后复活 |
| **按键 K2** | **PA1** | 赛车向右变道 / 桌宠下一表情 / 撞车后复活 |
| **按键 K3** | **PA2** | **赛车氮气极速喷火冲刺 (Boost)** / 桌宠戳一戳互动 / 撞车后复活 |
| **按键 K4** | **PA3** | **全局三合一模式切换**（双子萌 / 合体大脸 / 极速赛车） |
